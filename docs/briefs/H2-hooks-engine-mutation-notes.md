# H2+H3 hooks-engine mutation notes

Every law-bearing test below is a separate test source. “Expected RUNTIME
failure” means an assertion, timeout, or typed command failure—not merely a
compile error. The fixtures use literal commands, byte limits, decisions, and
backoff values rather than re-reading the production constants they pin.

| Production mutation | Runtime observer | Expected RUNTIME failure |
|---|---|---|
| Execute a default-untrusted hook or suppress its refusal. | `hooks::tests::untrusted_hook_never_executes_and_notices_honestly` | The forbidden marker appears or the durable notice does not name the exact untrusted refusal. |
| Hash parsed JSON, omit raw config bytes, omit the per-hook command, trust by name/path, or skip the pre-spawn re-read. | `hooks::tests::digest_is_raw_hooks_bytes_followed_by_command_bytes`, `digest_change_revokes_trust_before_fire`, and `trust_workspace_pins_its_first_digest_across_restart` | The literal BLAKE3 differs, an edited command creates its marker, or an edited workspace digest becomes trusted before/after reopen. |
| Follow a symlink, let a malformed nearest named entry fall through, silently accept a non-object `hooks`, or make discovery fatal. | `nearest_malformed_named_entry_reserves_the_parent_name`, `malformed_hooks_container_produces_an_honest_notice`, plus engine discovery notices | A valid parent command replaces the malformed nearest name, or the honest malformed-document notice disappears. |
| Dispatch from accepted memory before commit, omit the transaction-coupled outbox, acknowledge before handling, or enqueue a rejected append. | `matcher_fires_only_after_commit`, `committed_fact_survives_crash_before_publish_and_fires_on_recovery`, and `haider-store/tests/hook_dispatch_outbox_tests.rs` | A rejected duplicate creates a marker, a committed fact is absent after reopen, an acknowledged row remains, or rollback leaves phantom dispatch work. |
| Reconstruct only profile pins and forget durable run authority. | `run_scoped_hook_trust_is_reduced_before_recovery_dispatch` | The unpinned hook fails to run after the committed `HookRunTrust` + `RunStarted` batch survives restart. |
| Inherit descriptors or the parent environment. | `hook_spawn_is_live_but_inherits_no_descriptors_or_secret_environment` and its isolated `hook_secret_child_probe` | A live child observes the deliberately non-CLOEXEC descriptor 333, any non-allowlisted inherited variable, or the planted vault-sentinel bytes/name. |
| Keep unbounded output, omit CAS overflow/journaling, replace retained bytes, or bound before lossy UTF-8 expansion. | `exec_output_is_bounded_and_overflow_is_in_cas` and `invalid_utf8_preview_stays_within_the_byte_cap` | The durable HookFired bytes/artifact drift, exact `x\n` bytes are absent, or an invalid-byte preview exceeds literal 8192 bytes. |
| Restart subscribers immediately/linearly, raise the cap, silently drop queue-full/dead-sender facts, share one process across workspace CWDs, or kill only the shell. | `subscribe_restart_backoff_is_exponential_and_bounded`, `subscribe_restart_schedule_reaches_and_holds_the_five_second_cap`, `subscriber_identity_is_scoped_to_workspace_cwd`, and `subscribe_revoke_kills_the_entire_process_group` | Durable schedules differ from 200/400, the extracted schedule does not reach and hold 5000, keys collide across CWDs, delivery never acknowledges, or a background descendant writes after revoke. |
| Ignore subscribe hooks under run-scoped trust or let them outlive the run. | `run_scoped_trust_authorizes_subscribe_only_for_that_run` | The subscriber never starts, or its background descendant writes after terminal `Done`. |
| Let a decision hook bypass menu CAS, map `allow`/`deny` to persistent or wider scope, accept malformed output, invent an option, or erase provenance. | `decision_hook_allow_uses_existing_menu_cas_and_allow_once_only`, `decision_deny_is_reject_once_and_malformed_output_falls_through`, `decision_hook_cannot_exceed_committed_ask_scope`, and the `menu_answer_hook` golden | The answer is absent/wrong, does not select offered `AllowOnce`/`RejectOnce`, malformed output answers, an AllowAlways-only menu is answered, or provenance is not `via:"hook"`. |
| Answer after timeout, alter the pending Ask for hook consumption, or use a degenerate/handcrafted Ask fixture. | `decision_timeout_falls_through_to_byte_identical_ask` paired with the successful allow fixture | A MenuAnswered fact appears, the timeout fact is absent, or two independently frozen `EffectBroker` menus differ after the timeout world journals its MenuOpened payload. The paired non-timeout hook resolves the broker-produced menu. |
| Match account expiry against session metadata, ignore optional filters, or omit the digest from notice deduplication. | `matcher_filters_use_fact_specific_provider_outcome_and_parked_kind` and `untrusted_notice_dedup_is_digest_sensitive` | Account provider/outcome/parked filters fail, or an edited untrusted digest has no second honest refusal. |
| Put hook facts in closed `EventPayload` or rename their additive discriminants. | Protocol `hook_fired` golden and unknown-kind tolerance test | Exact JSON drifts or an older typed reducer no longer ignores the raw additive payload while `RawEnvelope` still round-trips it. |
| Apply trust/revoke outside the R2 receipt transaction, reuse a command id with changed coordinates, or share the management revision. | `haider-store/tests/hook_trust_tests.rs` | Replay/order diverges, changed coordinates are accepted, or the unrelated management revision advances. |
| Make `--trust-hooks` profile-global, append it after acceptance, emit it for ordinary runs, or change ordinary turn wire bytes. | Store atomic run-trust test, client `headless_submit_body` test, required-feature test, and RPC exact-shape test | The acceptance batch lacks the correlated run fact, ordinary submission gains one, the client chooses the wrong variant, or the feature/method set changes. |

The isolated secret fixture re-executes only its named test with
`HAIDER_HOOK_VAULT_SENTINEL` planted in the parent environment. This avoids a
process-global `set_var` race while proving secret bytes do not cross the hook
spawn boundary.
