## Items (fixed list — additions go to the NEXT round)

1. **Real cursor cell.** Kill the appended `▮`. The cursor is a STYLED CELL at the cursor position: the character under the cursor rendered reverse-video (fg↔bg swap using the composer's ground + gold accent — pick the exact treatment against dawn AND dark themes; at end-of-text the cell is a themed block over a space). Steady, no blink — the zero-idle-wakeup law is untouchable; `animated()` must NOT grow a composer term. Must sit correctly in ALL composer states: placeholder (cursor at col 0 over the placeholder start? — Claude Code shows the block before the dim placeholder; match that), single-line, multi-line autogrow rows, tail-windowed overflow, Aura composer, arg-slot mode.
2. **Cursor position model.** A grapheme-aware cursor index into the input buffer (unicode-segmentation or the existing unicode-width machinery — wide chars occupy 2 cells, combining marks move as one). Movement: ←/→ by grapheme; ⌥←/⌥→ by word; Home/End + ⌃A/⌃E line edges; ↑/↓ move across VISUAL wrapped rows of the multi-line composer (column-sticky like every editor). Arabic/RTL: LOGICAL-order movement (← = toward text start), documented; full bidi caret geometry is ledgered graphics-tier.
3. **Edit at cursor.** Typing INSERTS at the cursor (not append). Backspace deletes the grapheme before; Delete (fn⌫ / kDEL) after; ⌥⌫ word-back; ⌃W word-back (Claude Code parity), ⌃K kill-to-end, ⌃U kill-to-start. Paste (the existing bracketed-paste path) inserts AT the cursor. Submit/history/slash-command flows keep working with the cursor anywhere.
4. **Selection.** ⇧+movement extends a selection from an anchor (⇧←/⇧→/⇧⌥←/⇧⌥→/⇧Home/⇧End/⇧↑/⇧↓). Visual: selection cells get the theme selBg band; cursor cell stays distinct at the active end. Typing/paste REPLACES the selection; ⌫/Delete deletes it; ⌃C WITH an active selection copies it (pbcopy+OSC52 via the existing clipboard path, honest flash) and clears the selection — ⌃C with NO selection keeps its TUI4 meaning (navigate/quit) exactly. Esc clears selection before any other Esc meaning fires.
5. **Mouse in the composer.** Click inside the composer places the cursor at the clicked grapheme (nearest boundary; click on the row maps through the wrap). Drag WITHIN the composer creates a composer selection (auto-copy on release like the transcript, same flash). Region disambiguation: a drag that STARTS in the composer is a composer selection; starting in the transcript stays the TUI4b transcript drag. Hit-map stays value-carrying.
6. **History interplay.** ↑ on the FIRST visual row (no selection) = previous submitted input; ↓ on the LAST row = next/back to draft — Claude Code behavior. Recall places the cursor at end. If input history does not exist yet as a model concept, add the minimal per-session ring (transient, NOT persisted — the DTO must not grow; assert in the persistence tests).
7. **Tests + probe gate.** Unit tests for the grapheme edge cases (combining marks, wide CJK, the Arabic placeholder text, empty buffer, all kill commands, selection replace/delete, column-sticky ↑/↓). New `scripts/tui-probes/pty-probe-cursor.py` on probelib: drive real key sequences over the PTY (arrows incl. modifier encodings, type-in-middle, select+copy, history recall) and assert the SCREEN (cursor cell styling present at the right column, selection band visible, edited text correct). Hermetic, exit-nonzero, ladder sizes 118×36 + 90×10.
8. **State hygiene.** Cursor/selection/anchor live in the composer model, are cleared on submit/session switch per native-input rules, never enter the persistence DTO, and never arm anything. `/reset`, fresh_session, attach/detach leave no stale cursor state (the TUI4 identity laws apply unchanged).
