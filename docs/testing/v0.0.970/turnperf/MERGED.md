SHIP (table with evidence)
The premise needs one correction: the success path has nine ordered SQLite transactions, but they are WAL `synchronous=NORMAL`, not nine `F_FULLFSYNC`s. With one new provider-view block, the foreground path additionally performs two plain `fsync`s plus one `F_BARRIERFSYNC`. I use the requested 4 ms-equivalent for every commit/sync below; actual plain `fsync` is much cheaper and NORMAL commits usually do not sync.
