- No new timing was taken: `vm.loadavg` was unavailable under the sandbox, so the mandated load-before-timing condition could not be established.
- Add a pre-runtime exit probe for the true loader floor; the 4 ms `--version` value includes Tokio construction and is only a conservative upper bound.
- Keep fat LTO, `codegen-units=1`, split line tables, and symbol stripping (`Cargo.toml:97-106`). `debug=false`, more stripping, prelinking, or an explicit `dead_strip` are unlikely to beat the existing shipped shape without link-map evidence.
- Do not set `panic=abort`: the daemon deliberately converts panicked supervisors into terminalized outcomes (`crates/haider-daemon/src/worker.rs:3621-3677`), while PDF/TUI paths also recover panics (`crates/haider-pdf/src/lib.rs:104-131`; `crates/haider-tui/src/link.rs:147-160`).
- Do not re-propose default mimalloc: measured turn CPU regressed 17%, idle memory 35.6%, and post-40 memory 138.3% (`docs/testing/v0.0.969/memdaemon.md:141-174`).
- Regex/Unicode semantics are real search/TUI functionality, while the sole production embedded wordmark is only 13 KB (`crates/haider-tui/src/wordmark.rs:26-30`); remove them from headless exec through X3.2, not by weakening Unicode search or deleting assets.
